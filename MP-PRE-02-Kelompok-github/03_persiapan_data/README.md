  - `Pertemuan3_Persiapan_dan_Karakteristik_Data.md`: Dokumentasi sumber data PMP/SRS, alur preprocessing data, dan karakteristik statistik variabel.
- **Folder Arsip:**
  - `arsip_dataset/`: Menyimpan draf dataset iterasi terdahulu (`dataset_pre02_fne_v1_arsip.csv` dan `v2.csv`).
